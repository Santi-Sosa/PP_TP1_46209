# Trabajo Práctico N° 1 - Paradigmas de Programación - Sosa Santiago - 46209

## Descripción

Implementación en Java de un sistema para administrar eventos universitarios.

En el proyecto se puede:

- Crear eventos universitarios.
- Asignar salas.
- Crear actividades.
- Registrar estudiantes.
- Inscribir estudiantes en actividades.

## Ejercicios

### Ejercicio 1

Implementación inicial de la clase `EventoUniversitario`, sus atributos, constructores y métodos.

### Ejercicio 2

Incorporación de salas, actividades, estudiantes e inscripciones.

### Ejercicio 3

Incorporación de herencia y polimorfismo mediante las clases:

- `Actividad`
- `Charla`
- `Taller`

Además, `Actividad` se transforma en una clase abstracta y `mostrarIdentificacion()` se define como método final.

### Ejercicio 4

Elaboración de un mapa de memoria que representa las variables locales, objetos del heap y relaciones entre los objetos.
